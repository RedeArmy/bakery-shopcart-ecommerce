# Domain layer of checkout

**Responsibility:** Entities, value objects, domain services and domain errors.

**May contain:** Plain TypeScript with no I/O.

**Must not contain:** Imports from application, infrastructure or presentation, and any use of Express, mssql or zod.

**Governing ADR:** [0001](../../../../../docs/adr/0001-modular-monolith-with-vertical-slices.md)
